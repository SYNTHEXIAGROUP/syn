SYNTHEXIA GROUP — VERCEL DEPLOYMENT PACKAGE

This is a static website. The package is arranged with index.html at the ZIP root
and all images inside ./assets, using relative paths for reliable deployment.

DEPLOY WITH VERCEL
1. Extract this ZIP on your computer.
2. Open the extracted synthexia-vercel-ready folder.
3. In Vercel, choose Add New -> Project -> Deploy manually / upload the folder
   (or drag the extracted folder into the Vercel deployment area if available).
4. If importing from Git, put ALL files from this folder at the repository root.
5. Framework Preset: Other. Build Command: leave empty. Output Directory: leave
   empty (or use .). Install Command: leave empty.
6. Deploy. Do not upload only index.html; upload the complete folder including
   style.css, script.js, and assets/.
